# SPManchester Portfolio Projects — 01 · Web Design & Development

Concept/demo projects by SPManchester (https://spmanchester.com/). Every business below is **fictional**; each project is a complete, working static website (HTML/CSS/JS, no build step) built to answer a real market need, ready to publish as its own GitHub repo under https://github.com/serviceprovidermanchester and to feature at https://spmanchester.com/projects.

| # | Project | Market problem it solves | Interactive feature | Folder |
|---|---------|--------------------------|---------------------|--------|
| 1 | **Northgate Dental** — Family & cosmetic dentistry in Didsbury, Manchester | Dental practices lose patients at the phone. This site turns a brochure into a booking engine with transparent fees and a 60-second appointment request. | Appointment-request form: pick treatment, clinician, date & time slot and get an instant confirmation with a booking reference (client-side demo). | `spm-web-dental-clinic/` |
| 2 | **Saffron & Sage** — Modern British-Indian kitchen · Northern Quarter, Manchester | Restaurants pay commission for bookings they could own. ## How each project is packaged
- `index.html`, `styles.css`, `script.js` — the complete website (open index.html or host anywhere)
- `README.md` — pitch + how to run
- `PROJECT-DETAILS.md` — problem, solution, portfolio entry text for spmanchester.com, LinkedIn post draft
- `PRD.md` — detailed Product Requirements Document (market problem, personas, functional requirements with acceptance criteria, KPIs, scope, roadmap) — added 2026-11-10
- `TRD.md` — detailed Technical Requirements Document (as-built architecture, exact interactive logic and formulas, data model, security/performance/accessibility requirements, 8 test cases per project, production API contract and integrations) — added 2026-11-10
- `screenshots/` — preview images of the finished design
- A `.zip` of each project sits alongside its folder for one-click upload to Google Drive / GitHub.
