# Northgate Dental — Project Details

## Concept / demo notice
Northgate Dental is a **fictional business**. This is a concept/demo project built by SPManchester to
demonstrate Web Design & Development capability. Sample prices, reviews and figures are illustrative.

## Business problem (market need)
Independent dental practices lose patients at the phone: reception is busy, fees are hidden, and nervous patients put off calling. Most clinic websites are digital leaflets with no booking path, so enquiries leak to chains with online booking.

## Solution built
A trust-first clinic website with transparent fees, treatment explainers written for anxious patients, and a working appointment-request flow (treatment, clinician, preferred time) that gives an instant on-screen confirmation with a reference — the exact enquiry engine a real practice can plug into its diary system.

## Interactive feature (working demo)
Appointment-request form: pick treatment, clinician, date & time slot and get an instant confirmation with a booking reference (client-side demo).

## Pitch in one line
Dental practices lose patients at the phone. This site turns a brochure into a booking engine with transparent fees and a 60-second appointment request.

## Features
- Responsive, mobile-first design with a modern 2026-standard look (sticky nav, gradient hero, card layouts)
- Problem → Solution storytelling section, written to pitch the service to a client
- Appointment-request form: pick treatment, clinician, date & time slot and get an instant confirmation with a booking reference (client-side demo).
- FAQ section and sample testimonials (clearly labelled as sample content)
- SEO-ready: semantic HTML, meta description, descriptive headings
- Zero dependencies — opens and hosts anywhere

## Tech stack
HTML5 · CSS3 (custom properties, grid/flex, media queries) · Vanilla JavaScript

## How to run / host
Open `index.html` directly, or deploy the folder to GitHub Pages / Netlify / any static host.
